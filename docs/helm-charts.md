# Helm chart catalogue

This catalogue covers all 65 HelmRelease objects in the repository. Chart
versions are taken from each HelmRelease or its referenced OCIRepository. They
are chart versions, not application image versions. Multiple releases may use
the same chart; in particular, app-template supplies generic Kubernetes
resources while each release configures its own application image and values.

Upstream **docs** links are moving references unless their URL specifies a
version. **Package** links come from the upstream index entry for the exact
pinned version; inspect those artifacts for bundled documentation, default
values and templates.
OCI sources below include the configured repository and tag; use that exact tag
when inspecting defaults with Helm. A chart absent from the current index is
identified below rather than substituted with another release.

Local values and operating guides remain authoritative for this installation.
Use the linked manifest for values, secrets references and resource settings.
Some declared releases may be suspended; this is a repository inventory, not a
claim that every release is healthy or deployed.

## Reading and changing a deployment

1. Open its local values and guide, then read the upstream defaults for the
   pinned chart version. For app-template, read the application image's own
   documentation as well as the generic chart reference.
2. Render the existing chart with the proposed values before changing the pin.
3. Use repository render/schema checks and Docker Desktop Kubernetes for local
   deployment verification. Static rendering does not prove storage,
   authentication or network-policy behaviour.
4. Update this catalogue when adding, removing or changing a chart reference.
